# VKIntox v0.2.1 is out! 🎉

A release focusing on Sober compatability and some UI polishing.

This is a Stable release, meaning it is fully polished, and ready to use in production.

### From v0.2.0, here's what's new:

- **Sober compatability was re-introduced**: the Wayland interpose patch made it jump into garbage due to Sober's JIT, so we simply had to revert the change.

- **The dock fades with the overlay now**: when toggling the overlay, the dock now fades along with the rest of the overlay

- **Cards reserve space for scrollbars**: previously, scrollbars had rendered behind cards, which made it look cut off. Now cards reserve space for scrollbars, and scrollbars render above cards.

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://github.com/buwryme/Roseline) support!

> When installing for Flatpak, you might want to set `ENABLE_VKINTOX=1` into the game itself, not its launcher (for example, Steam?)

### Other, boring, non-user-siding changes:

- **Gated queue presents were reverted**: it was also reportedly part of what made Sober crash.

Have fun!
