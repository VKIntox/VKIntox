# VKIntox v0.2.2 Preview 2 is out!

A preview focusing on the overlay.

This is a **Preview release**, meaning it may have rough edges, is a testing build, and is not the final shape of what v0.2.2 will be.

## What's new from Preview 1:

- **Floating Apply bar**: The apply button moved into its own designated floating area next to the Show FPS and Auto-apply checkmarks. Thank you @arcthurr for this!

- **FPS counter**: a small pill that sits in a corner you choose, with optional 1% and 0.1% lows. Yet again, thank you @arcthurr .

- **Persisted overlay position**: the overlay now persists its last position

- **Double cursor rendering fixed on Wayland**: the overlay now draws its own cursor *only*, instead of stacking the system's and ImGui's together. Thank you @arcthurr .

- **Switches are now faster, and more bouncy**.

**Full Changelog**: https://github.com/VKIntox/VKIntox/compare/v0.2.2-preview.1...v0.2.2-preview.2

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://buwryy.net/roseline) support.

> When installing for Flatpak, set `ENABLE_VKINTOX=1` on the game itself, not its launcher. The Flatpak layer targets `org.freedesktop.Platform` 26.08.

### Other, boring, non-user-siding changes:

- Frame timing moved to a shared module, that Diagnostics and the FPS pill use
- The X11 grab handoff drops already-released input instead of handing back phantoms that nothing would ever release.
- Input grabs release the moment the overlay starts closing, instead of holding them through the disappear animation, which had caused a re-open bug on X11.
