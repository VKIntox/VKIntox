# VKIntox v0.2.2 is out! 🎉

A stability and toolchain release: diagnostics are now accurate, export cruft is gone, and every CI build — including all release packaging — runs on Clang/LLVM.

This is a Stable release, meaning it is fully polished, and ready to use in production.

### From v0.2.1, here's what's new:

- **Diagnostics FPS is accurate**: the sampler ran twice per overlay frame, so the FPS counter read exactly double the real rate. Diagnostics now sample once per frame, and the counter matches tools like MangoHud.

- **"Save frame stats" removed**: the diagnostics CSV export button is gone.

- **Fully Clang/LLVM builds**: GitHub Actions, every release package (Arch, RPM, Debian, Nix), and the Flatpak build now compile with clang via the `org.freedesktop.Sdk.Extension.llvm-22` SDK extension. Earlier the Flatpak still built with GCC.

- **Vendored ReShade compiler hardening**: `find_texture` and `find_function` throw on malformed input instead of dereferencing past-end iterators, matching the `find_struct` style the codebase already used.

- **Backend cleanliness**: unused headers pruned across the core, overlay and render modules, and the `mapedBuffer` typo renamed to `mappedBuffer` throughout the uniforms.

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Include [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://github.com/buwryme/Roseline) support!

> When installing for Flatpak, you might want to set `ENABLE_VKINTOX=1` into the game itself, not its launcher (for example, Steam?)

### Other, boring, non-user-siding changes:

- **Compile warnings zeroed out**: toast label and duplicate-counter buffers widened for `-Wformat-truncation`, a trailing-backslash comment fixed, and clang-only dead code removed.

Have fun!
