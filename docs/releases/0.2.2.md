# VKIntox v0.2.2 is out! 🎉

A big release focused on the overlay, FX-Over-UI, arm64 builds, and a pile of performance work.

This is a **Stable** release, meaning it is fully polished and ready to use in production.

## Highlights since v0.2.1

- **FX-Over-UI for Roblox**: effects now draw with Roblox's HUD untouched. This works for Sober and Roblox on Rosemary. Other games can flip the switch, Thanks @arcthurr for MangoHud protection and bringing back Roblox's own FPS counter!

- **Native arm64 packages**: Arch, Debian, Fedora, openSUSE, Flatpak and Nix now ship aarch64 builds. The setup script detects the architecture automatically.

- **Show FPS**: a floating FPS pill that optionally has 1% and 0.1% lows.

- **Overlay refinements & new features**: a floating Apply bar that has a toggle for Show FPS and auto applying, smoother switches, only-single cursor rendering on Wayland & persisted overlay position (thx @arcthurr !!). You can now resize the overlay from any corner.

- **Input blocking was rebuilt**: Wayland tracks hovers from the capture surface instead of last frame's pointer position, keyboard blocking works properly on X11 and Wayland, and X11 blocks with invisible input windows instead of pointer grabs so Wine games keep their cursor capture. Turning "block input while the overlay is open" off now applies immediately.

- **Cheaper effects**: redundant work is cut, expensive effects can render at a lower scale, static uniforms are skipped, and uniforms bake into a more optimized form once parameters settle.

- **New built-in effects**: SSR, MXAO, RimLight and depth color correction. SSR and MXAO include render-size scaling for performance.

- **Depth fixes**: sample-zero depth skips the MSAA average resolve, and depth method/rebuild changes apply safely.

- **Compiler hardening and Clang**: the vendored ReshadeFX compiler rejects malformed input instead of reading past the end, all release packages and the Flatpak now build with Clang, and existing signal handlers are preserved outside the shader compile guard. Thanks @staraepp for signal chain safety!

## Some refinements since Preview 3

- View transitions no longer leave tab content offset while the game window is dragged.

- The overlay backdrop blur compounds its radius on every pass, ensuring more passes don't make the blur look blocky.

- Switch thumbs, slider knobs and radio marks are tessellated finer instead of looking jaggy.

- The FPS pill now draws above the overlay shell.

- The About footer uses a fixed bottom position, to aid it jittering on dragging the overlay.

- Setup fixes: a bug affecting Fedora/Flatpak version selection was fixed, and previews now sort properly.

## Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://buwryy.net/roseline) support.

> When installing for Flatpak, set `ENABLE_VKINTOX=1` on the game itself, not its launcher. The Flatpak layer targets `org.freedesktop.Platform` 26.08.

### Other, boring, non-user-siding changes:

- In-process presenters stay off the effect machinery.
- Per-command device lookups come from a snapshot, and hot-path trace strings are built lazily.
- The setup script rejects placeholder Flatpak app IDs.
- X11 grab handoff drops already-released input instead of handing back phantom releases.
- Input grabs release as the overlay starts closing instead of after the disappear animation.
- Frame timing uses a shared module between Diagnostics and the FPS pill.
- Cards reserve space for scrollbars, and scrollbars render above cards.
