# VKIntox v0.2.0 is out! 🎉

This is by far the biggest VKIntox release yet. The overlay has been rebuilt from scratch on an opinionated design heavily inspired by Google's Material 3, depth capture finally behaves itself, and lots of crashes were fixed.

This is a Stable release, meaning it is fully polished, and ready to use in production.

### From v0.1.2, here's what's new:

- **The overlay is a real Material 3-inspired shell now:** the UI has been overhauled thoroughly!

- **The navigation bar is yours:** you can customize the navigation bar to switch between 2 styles and 2 positions.

- **The frame behind the overlay blurs:** the overlay now has dynamic frost blur!

- **A full theme editor:** you can change the seed color the UI will use, control density and shape sizes...

- **Effect parameters moved into their own sheet:** a tabbed card at the bottom instead of one card doing toggling, reordering and parameters at once. Can be switched off!

- **A proper add-effects view:** package tabs (all / vkintox / every installed pack), ranked search, recents, and an easier effect-duplicating experience.

- **The shader manager compile-tests your shaders:** every discovered `.fx` gets compile-tested. You can refresh and re-compile all in one session, in case you add a new `.fx` file.

- **Depth works on the first launch:** VKIntox is now stable enough to allow having depth capture ON by default! We also fixed a lot of depth rebuild related crashes (VKIntox now survives swapchain rebuilds, on games like Roblox where that happens routinely).

- **Input blocking actually works:** input blocking logic has been reimagined to block input only on the overlay, and pass through to the game when the cursor isn't hovered on the overlay. Keyboard blocking is intentionally disabled, due to some Wine games reportedly having their keyboard input locked.

- **X11 support was introduced!** This release introduces X11 input backends.

- **XDG Desktop Portal integrations:** picker dialogs now go through XDG Desktop Portal file pickers when available, falling back to ImGui's built-in. Can be switched off!

- **Intel iGPU support:** VKIntox's GPU support field widens, beginning with the UHD Graphics lineup.

- **We now have our own built-in effects:** the installer now ships our in-house MSAA and exponential-height-fog shaders, pulled from their repo.

- **Cross-distro system builds:** we now have builds for Debian, Arch, Fedora, openSUSE, Nix and Flatpak (as a `.flatpak`).

- **The setup script was massively overhauled:** select between system-wide or Flatpak (then choose the Flatpak App ID), fetch ReShade packages or not, choose a version, confirmation...

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes Rosemary/[Roséline](https://github.com/buwryme/Roseline) support!

> You might want to set ENABLE_VKINTOX=1 into the game itself; not the game launcher. (e.g. steam env variables). Remove it with Flatseal.

### Other, boring, non-user-siding changes:

- **ImGui, ReShade, VKIntox Effects now live in their own public repositories:** [`imgui-material-3`](https://github.com/buwryme/imgui-material-3) (MIT) and [`reshade-vkintox`](https://github.com/buwryme/reshade-vkintox) (BSD-3). They are submodules now, and the build fetches them itself, so a clone plus `just configure` is all you need.
- **No more font binaries in the repo:** the installers fetch from Google Fonts and install the SIL OFL licences beside them, system installs included.
- **We now have a publish release workflow:** which is what this release uses!
- **The smoke test now drives depth rebuilds under a live queue.**
- **New config keys** in `VKIntox.conf`: `depthRebuildMode`, `usePortalIntegration`, `navPosition` and `navStyle`.
- **Backend** was overhauled to wrap *every* C resource in RAII, and lots of general stability improvements were made. Expect a lot fewer crashes.

Have fun!
