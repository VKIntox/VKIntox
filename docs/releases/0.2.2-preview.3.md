# VKIntox v0.2.2 Preview 3 is out!

A wrap-up preview for v0.2.2.

This is a **Preview release**, meaning it may have rough edges, is a testing build, and is not the final shape of what v0.2.2 will be.

## What's new from Preview 2:

- **Input blocking was rebuilt from the ground-up**: Wayland: the overlay now tracks hovers straight from its capture surface, instead of assuming from the last frame's pointer position. Keyboard blocking now works properly (X11 and Wayland). Input lag while hovered on the overlay on Sober's homescreen is mostly fixed.

- **Keyboard blocking, as well, now works**: every key now belongs to its proper receiver, meaning nothing leaks into the game. However, on X11, the keyboard is only taken while needed (when a text field or popup is open and has focus) and is immediately released after. There is also a watchdog that automatically lets go on a detected stall. This is mostly to fix keyboard blocking behaviour on specifically Wine + X11, as keyboard blocking was never really released.

- **No more pointer grabs on hover (X11)**: clicks and motion over the overlay are blocked by invisible input windows instead of a grab, so Wine games never see grab focus events from a pointer crossing and keep their cursor capture.

- **"Block input while the overlay is open" applies live*: turning it off now stops the blocking immediately. This had mostly only affected Wayland.

- **Resize the overlay from any corner**: the overlay can now be resized from any corner. However, left, right, top & bottom resizing was removed.

- **A neater toggle feedback**: flipping FX-Over-UI or the depth buffer now shows a toast, shown only once.

**Full Changelog**: https://github.com/VKIntox/VKIntox/compare/v0.2.2-preview.2...v0.2.2-preview.3

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://buwryy.net/roseline) support.

> When installing for Flatpak, set `ENABLE_VKINTOX=1` on the game itself, not its launcher. The Flatpak layer targets `org.freedesktop.Platform` 26.08.

### Other, boring, non-user-siding changes:

- A bug in the setup script's version picker was fixed.
- Previews now ship as pre-release.
- The X11 handoff keeps held buttons honest across the keyboard grab, and dead shield windows from a destroyed game window are never touched again.
- Fixed a bug where releases wouldn't be matched properly, for Fedora and Flatpak.
