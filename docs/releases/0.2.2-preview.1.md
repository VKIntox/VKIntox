# VKIntox v0.2.2 Preview 1 is out!

A preview release focused on FX-Over-UI, arm64 builds and a pile of performance work.

This is a **Preview release**, meaning it may have rough edges, is a testing build, and is not the final shape of what v0.2.2 will be.

## What's new since v0.2.1:

- **FX-Over-UI for Roblox only**: Effects now work fully ignoring Roblox's HUD. This matters most for people who heavily overhaul their Roblox with VKIntox, and would like gameplay to stay visually uninterrupted. This works only for Sober and Roblox-on-Rosemary. Other games can flip the switch, but this has only ever been tested for Roblox.

- **Also, additional work on FX-Over-UI**: MangoHud protection. VKIntox and MangoHud can now be properly layered. Thank you @arcthurr for this! This also reportedly restores Roblox's own FPS counter, which appears with `SHIFT + F5`.

- **Native arm64 packages**: Arch, Debian, Fedora, openSUSE, Flatpak and Nix now ship aarch64 builds. Remote setup script was also updated accordingly with auto-detection.

- **Cheaper effects**: redundant effect work is cut, expensive effects can now downscale (... and well, upscale, too), static uniforms are skipped, and the effects bake themselves into a more optimized, static form once you're done with tweaking parameters.

- **Depth fixes:** sample-zero depth now skips the MSAA average resolve, depth method and rebuild settings are now applied safely.

- **New built-in effects:** SSR, MXAO, RimLight and depth color correction are new. SSR and MXAO include render size scaling, which can help a lot with performance.

- **Compiler hardening:** the vendored ReShade compiler now rejects malformed input instead of reading past the end.

- **Clang/LLVM everywhere:** all release packages and the Flatpak now build with Clang.

- **Signal safety:** VKIntox now preserves existing signal handlers outside the shader compile guard. Thank you @staraepp ! This was groundwork for getting arm64 builds.

**Full Changelog**: https://github.com/VKIntox/VKIntox/compare/v0.2.1...v0.2.2-preview.1

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://github.com/buwryme/Roseline) support.

> When installing for Flatpak, set `ENABLE_VKINTOX=1` on the game itself, not its launcher. The Flatpak layer targets `org.freedesktop.Platform` 26.08.

### Other, boring, non-user-siding changes:

- In-process presenters stay off the effect machinery.
- Per-command device lookups come from a snapshot, and hot-path trace strings are built lazily.
- The setup script now rejects placeholder Flatpak app IDs.

Have fun! :)
