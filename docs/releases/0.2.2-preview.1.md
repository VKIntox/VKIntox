# VKIntox v0.2.2 Preview 1 is out! 🎉

The first preview, developer, beta, whatever-you-want-to-call-it pre-release of v0.2.2.

This is a Preview release, meaning it is feature-complete for v0.2.2 but not yet fully polished - meaning, you can help find bugs and report them.

### From v0.2.1, here's what's new:

- **Effects skip HUD now, on Roseline**: Effects occlude HUD on Roblox (specifically, on Roseline) and are fed the effect-free backbuffer. This means you get more accurate reflections, that won't have the UI inside them. This feature is automatically disabled for anything not determined as Roseline, as it simply breaks other games. To be adapted to other games for v0.2.2 Preview 2, or the final release. While at that, some potential gaps for VRAM leaking were fixed.

- **Four new built-in effects**: IntoxMXAO, IntoxSSR, IntoxDepthColorCorrection and IntoxRimlight are now built-in. Uses logic inspired by qUINT, and also has stuff like render size scaling and a bit more customizability

- **A more optimized per-frame loop**: uniform bindings automatically bake themselves when the layer senses you are done tweaking effect parameters. This is similar to ReShade's Performance Mode but doesn't need a toggle, as it is automated.

- **ARM64 builds**: VKIntox now fully functions and packages on arm64!

#### Install (Universal)

```bash
curl -fsSL https://buwryy.net/api/vkintox/setup-script | bash
```

Includes [Sober](https://sober.vinegarhq.org) and Rosemary/[Roséline](https://github.com/buwryme/Roseline) support!

> When installing for Flatpak, you might want to set `ENABLE_VKINTOX=1` into the game itself, not its launcher (for example, Steam?)

### Other, boring, non-user-siding changes:

- **src/ reorganized**: the tree is now split into clearer modules (core, effects, layer, input, overlay, render, shaders), and unused headers were pruned across the core, overlay and render modules.

- **Compile warnings zeroed out**: all previously existing compiler warnings were fixed.

- **Compiling no longer fails, as C++20 was enforced**: thank you arthur for this

- **Installer hardening**: the setup script and the Flatpak build reject placeholder app IDs.

### What should we anticipate in new versions?

v0.3.0 is planned to bring **frame generation via `lsfg-vk`**, and possibly Android support, for which the arm64 builds are foundation.

Have fun!
