# VKIntox v0.3.0 Preview 1 is out! 🎉

Frame generation is here. This preview adds an optional MAKO-backed frame generator, which, as a result, rebuilds the way VKIntox presents.

This is a **Preview release**: frame generation is still experimental and may have rough edges. It has been tested primarily with Roséline/Roblox.

Also the first release published on Forgejo!

## What's new since v0.2.2:

- **Frame generation with MAKO:** generate up to three extra frames per real frame, from the FG tab. Off by default.
This may still have rough edges. You can [open an issue](https://git.buwryy.net/VKIntox/VKIntox/issues) to help.

Frame generation adds a new tab called "FG", inside which it has options for:
> * Multiplier: 2-4x
> * Performance mode switch (more performance for a small quality cost)
> * Flow scale (resolution the computing runs at)
> * FX-Over-UI switch (occlude Roblox HUDs for frame generation)

Frame generation applies only to the backbuffer, and doesn't apply to the overlay nor the FPS counter.

Also, KeyUniform was implemented, which comes from v0.2.3 work, that this branch had originally been based off of. v0.2.3 itself, however, is still in development.

**Full Changelog**: https://git.buwryy.net/VKIntox/VKIntox/compare/v0.2.2...v0.3.0-preview.1
